# 07. Project Documentation

## Project Overview
EduGenie is a lightweight AI-powered educational assistant designed to simplify learning using generative AI.

## Key Features
- Question answering
- Simplified concept explanation
- Quiz generation
- Text summarization
- Personalized learning recommendations

## Technology Stack
- Python 3.10+
- FastAPI
- HTML
- CSS
- Jinja2
- Uvicorn
- Google Gemini API
- LaMini-Flan-T5-783M

## How the System Works
The user selects an educational task and enters text or a question through the web interface. The request is sent to the FastAPI backend, which connects it to the appropriate module and AI model. The generated result is then displayed on the webpage.

## Educational Value
EduGenie supports quick revision, simplified understanding, practice through quizzes, and structured learning guidance.

## Challenges Mentioned in the Project
- Ensuring accuracy of AI-generated responses.
- Maintaining performance across devices.
- Balancing personalization with general usability.
- Addressing data privacy concerns.
