# 04. Project Planning

## Project Objective
To develop a lightweight AI-powered learning assistant that helps learners understand, revise, practice and plan their learning using generative AI.

## Planned Milestones

### Milestone 1 – Model Selection and Architecture
- Select suitable AI models.
- Define the application architecture.
- Organize the project folder structure.

### Milestone 2 – Core Functionalities Development
- Develop the explanation module.
- Develop Q&A functionality.
- Develop quiz generation.
- Develop summarization.
- Develop learning recommendations.
- Connect modules through FastAPI endpoints.

### Milestone 3 – Frontend Development
- Build the HTML interface.
- Add task selection.
- Add input area and submit button.
- Add CSS styling.
- Connect frontend with backend.

### Milestone 4 – Deployment and Testing
- Run the application locally using Uvicorn.
- Access the application through the local browser.
- Perform functional checks for all major features.
