# 08. Project Demonstration

## Running the Application

### Step 1
Install the required Python environment and dependencies.

### Step 2
Configure the Google Gemini API key securely.

### Step 3
Start the FastAPI application:

```text
uvicorn main:app --reload
```

### Step 4
Open the application in a browser:

```text
http://127.0.0.1:8000
```

## Demonstration Features

### 1. Asking Questions
Select the Q&A task and enter a question. EduGenie returns an AI-generated answer.

### 2. Explaining a Topic
Select the explanation task and enter a topic. EduGenie provides a simplified explanation.

### 3. Summarizing
Enter a long educational paragraph and use the summary feature to receive a concise version.

### 4. Generating a Quiz
Provide a passage and generate three multiple-choice questions with four options each.

### 5. Learning Recommendations
Enter a topic to receive a structured learning path from beginner to advanced level, along with learning resources.
